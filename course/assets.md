# Основные средства, НМА и оборотные средства

[Постраничный указатель трёх презентаций](pages-assets.md)

На контрольной сначала определи, о чём спрашивают: стоимость или амортизация объекта, движение ОС, загрузка оборудования, скорости бурения, использование фонда скважин или оборачиваемость средств. Формулы, единицы и примеры собраны ниже. Номера в ссылках соответствуют страницам PDF.

## Формулы

### Стоимость и амортизация

| Величина | Формула и условия | Источник |
| --- | --- | --- |
| Балансовая стоимость | `Фбал = Фп − ΣА − Об`, где `Фп` — первоначальная стоимость (при модели переоценки используется переоценённая база), `ΣА` — накопленная амортизация, `Об` — накопленное обесценение | [ОС, 34–38] |
| Ликвидационная стоимость | `Флик = ожидаемые поступления при выбытии − затраты на выбытие`. Объект мысленно доводят до состояния на конец СПИ | [ОС, 40], [НМА, 21] |
| Линейная амортизация по ФСБУ | `А = (Фбал − Флик) / СПИост`, балансовая стоимость и оставшийся СПИ на начало расчётного периода. Для месячной суммы СПИ в месяцах | [ОС, 49], [НМА, 20] |
| Линейная при нулевой ликвидационной стоимости и неизменных оценках | `На = (1 / СПИ) × 100%`, `А = Фп × На / 100`, если `На` записана числом процентов. Используй полный СПИ при расчёте этой нормы | [ОС, 56–59] |
| Уменьшаемый остаток | По ФСБУ формулу выбирает организация, чтобы отчисления за равные периоды систематически уменьшались. В таблице лекции показана упрощённая формула `А = Фбал × На × К / 100`, где в этой таблице `К ≤ 3`. К концу СПИ балансовая стоимость должна достигнуть ликвидационной | [ОС, 49], [ОС, 56–59], [НМА, 20] |
| Пропорционально выпуску | `А = (Фбал − Флик) × Qпериода / Qост`, где `Qост` — оставшийся ожидаемый натуральный выпуск на начало периода. При нулевой ликвидационной стоимости, неизменном плане и отсутствии обесценения это эквивалентно `Фп × Qпериода / Qвесь` из таблицы лекции | [ОС, 56–59], [ОС, 94], [НМА, 20] |

Амортизационные группы по СПИ в годах: 1-я — от 1 до 2 включительно, 2-я — свыше 2 до 3 включительно, далее интервалы `(3; 5]`, `(5; 7]`, `(7; 10]`, `(10; 15]`, `(15; 20]`, `(20; 25]`, `(25; 30]`, свыше 30. Например, 15 лет входят в 6-ю группу. [ОС, 56–59]

Бухучёт по ФСБУ использует линейный способ, уменьшаемый остаток или начисление пропорционально натуральному объёму. В налоговом учёте в лекции выделены линейный и нелинейный методы. В бухгалтерском учёте по ФСБУ 6/2020 старт — с даты признания или по принятому решению с 1-го числа следующего месяца. Схема с началом после месяца ввода в эксплуатацию на с. 65 относится к налоговому порядку. Условия повышения налоговой нормы, приведённые на с. 61–64, требуют обращения к правилу для года задачи и конкретного основания. [ОС, 49], [ОС, 51], [ОС, 61–65]

### Движение и эффективность ОС

| Величина | Формула |
| --- | --- |
| Стоимость на конец года | `Фкг = Фнг + Фвв − Фвыб` при отсутствии иных изменений |
| Среднегодовая стоимость по двум датам | `Фср = (Фнг + Фкг) / 2` |
| Среднегодовая при известном графике движения | `Фср = Фнг + Σ(Фввᵢ × mᵢ / 12) − Σ(Фвыбⱼ × nⱼ / 12)`, где `mᵢ` — месяцы, когда введённые ОС учитываются в остатке года, `nⱼ` — месяцы отсутствия выбывших ОС. Это средневзвешенная по времени стоимость. Соглашение о неполных месяцах берётся из условия |
| Фондоотдача | `Фо = Q / Фср`, руб./руб. при стоимостном выпуске или натуральных единиц на рубль |
| Фондоёмкость | `Фе = Фср / Q = 1 / Фо` при одинаковом `Q`, руб./руб. или руб. на натуральную единицу |
| Фондовооружённость | `Фв = Фср / Ч`, где `Ч` — среднесписочная численность промышленно-производственного персонала, руб./чел. |
| Обновление | `Кобн = Фвв / Фкг` |
| Выбытие | `Квыб = Фвыб / Фнг` |
| Относительный прирост к началу периода | `(Фкг − Фнг) / Фнг = (Фвв − Фвыб) / Фнг` при изменении только из-за ввода и выбытия |
| Износ | `Кизн = ΣА к концу / Фп к концу`. При постоянной линейной норме для группы `ΣАᵢ = Фпᵢ × (Наᵢ / 100) × Тэкспᵢ`. Норма и время должны относиться к одинаковой единице периода |
| Годность | `Кгодн = 1 − Кизн` по лекции |
| Удельный вес активной части | `Факт.части / Фвсего × 100%` на одинаковую дату и по одной базе оценки |
| Экстенсивное использование | `kэ = Тф / Тк`, фактически отработанное время к календарному (или к заданному в задаче нормативному) фонду времени |
| Интенсивное использование | `kи = Qф / Qпл`, производительность в одну и ту же единицу времени |
| Интегральное использование | `kинт = kэ × kи` |

**Разночтение в исходнике.** На страницах 67 и 69 действительно напечатано `Крост = (Фнг − Фвыб) / Фкг`. Это выражение не даёт нулевой прирост при отсутствии движения. Если задача просит переписать формулу со слайда, цитируй её с оговоркой. Если задача просит посчитать, на сколько процентов выросли ОС, используй изменение стоимости и явно укажи базу сравнения. Для износа знаменатель берётся по первоначальной стоимости, как в формуле слайда 70. [ОС, 67–71]

### Бурение и фонд скважин

| Величина | Формула и единицы |
| --- | --- |
| Загрузка оборудования по стадиям | `kэ.см = Тпр.см / Тк.см`, `kэ.б = Тпр.б / Тк.б`, `kэ.и = Тпр.и / Тк.и` для строительно-монтажных работ, бурения и испытаний |
| Загрузка по циклу | `kэ.ц = (Тпр.см + Тпр.б + Тпр.и) / (Тк.см + Тк.б + Тк.и)`. Складываются времена по стадиям, а не коэффициенты |
| Механическая скорость проходки | `Vм = A / tм`, м/ч, где `A` — проходка, `tм` — время работы долота |
| Проходка на долото | `dср = A / Д`, м/долото, где `Д` — число отработанных долот |
| Рейсовая скорость | `Vр = A / (tм + tсп)`, м/ч, где `tсп` — время спуско-подъёмных операций |
| Техническая скорость бурения | `Vт = A / Тт`, м/станко-месяц, где `Тт` — время технически необходимых работ |
| Коммерческая скорость бурения | `Vк = A / Тб`, м/станко-месяц, где `Тб` включает технически необходимые работы, аварии, внеплановые ремонты и прочие потери времени бурения |
| Цикловая скорость бурения | `Vц = A / Тц`, м/станко-месяц, где `Тц` — весь цикл строительства скважины |
| Интенсивное использование бурового оборудования | `kи = Vк / Vт` |
| Скважины, законченные строительством | `N = Nэ + Nр`, эксплуатационные плюс разведочные |
| Потребность в новых эксплуатационных скважинах | `Nэ = (Q − Qп) / (qп × 183 × Кэ.н) − Nн.р − Nн.о`, где `Q` — план добычи, `Qп` — добыча переходящего фонда, `qп` — суточная продуктивность новой скважины, `183` — принятые в формуле дни, `Кэ.н` — коэффициент эксплуатации новых скважин. Вычитаются готовые к вводу скважины из разведочного бурения и опробования прошлых лет |
| Использование добывающего фонда | `kисп = Сэ / Ск`, где `Сэ` — фактически отработанное время действующего фонда, `Ск` — календарный фонд всего добывающего фонда |
| Эксплуатация действующего фонда | `kэксп = Сэ / Сд`, где `Сд` — календарное время действующего фонда |
| Добывающий фонд, год | `Ск = (365 × Nэ + Nн × tн − Nл × tл) / 30`, где `Nэ` здесь — добывающий фонд на начало, `Nн` — ввод новых, `Nл` — ликвидация |
| Действующий фонд, год | `Сд = (365 × Nд + Nвб × tвб + Nнд × tнд − Nв × tв) / 30`, где `Nд` — действующие на начало, `Nвб` — ввод из бездействия, `Nнд` — новые из бурения, `Nв` — вывод в бездействующий фонд |

Для корректировок календарного фонда `t` — число дней от соответствующего ввода или вывода до конца периода, по группам дат можно суммировать отдельные слагаемые. Один станко-месяц и один скважино-месяц по лекции равны 30 дням или 720 часам. При одинаковой проходке и сопоставимых единицах времени `Vц ≤ Vк ≤ Vт`. Печатные обозначения на с. 74–75 расходятся с текстом: для времени долота в формуле стоит `tᵥ` и для коммерческой скорости стоит `Тк`. В таблице выше использованы определения из текста. [ОС, 73–81]

### Оборотные средства

| Величина | Формула | Что показывает |
| --- | --- | --- |
| Коэффициент оборачиваемости | `Коб = РП / ОбСср` | Число оборотов за период |
| Коэффициент загрузки | `Кз = ОбСср / РП = 1 / Коб` | Рубли оборотных средств на рубль реализации |
| Длительность оборота | `Тоб = Тпер / Коб = Тпер × ОбСср / РП` | Дни в одном обороте, по примеру курса год — 360 и квартал — 90 дней |
| Средний остаток по двум датам | `ОбСср = (ОбСнач + ОбСкон) / 2` | Простая средняя при наличии только этих данных |
| Высвобождение при ускорении | `Э = (РП₁ / Тпер) × (Тоб₀ − Тоб₁)` | Вывод из формулы длительности: экономия средств в текущем периоде при сравнении со старой скоростью и текущей реализацией |

`РП` — реализация в рублях за тот же период, что и средний остаток. Рост `Коб` и снижение `Тоб` при прочих равных уменьшают потребность в средствах на данную выручку. [ОбС, 16–17]

## Решённые задачи

### Амортизация скважины

**Пример из лекции.** Первоначальная стоимость 30 млн руб., СПИ 15 лет, ликвидационная стоимость в расчёте принята нулевой. Переводим срок: `15 × 12 = 180 мес.` Месячное отчисление `30 000 000 / 180 = 166 666,67 руб.`, на слайде округлено до **166 667 руб./мес.** За год — 2 млн руб. при 12 полных месяцах начисления. Амортизация включается в эксплуатационные затраты (OPEX). Для полного срока не умножай округление до целых рублей на все 180 месяцев. [ОС, 56–59]

**Тренировка с остаточным СПИ.** Балансовая стоимость 2,4 млн руб., ликвидационная 0,4 млн руб., осталось 40 месяцев. Линейно `(2,4 − 0,4) / 40 = 0,05 млн руб./мес.` Через 40 месяцев останется ровно 0,4 млн руб. Если вместо календарного СПИ задан оставшийся ресурс 100 000 ед., а выпущено 12 500 ед., то `(2,4 − 0,4) × 12 500 / 100 000 = 0,25 млн руб.` [ОС, 49], [ОС, 94]

### Движение и эффективность ОС

**Тренировка.** На начало 80 млн руб., введено 30 млн руб., выбыло 10 млн руб., годовой выпуск 180 млн руб., 90 работников. На конец `80 + 30 − 10 = 100` млн руб., средняя по двум датам `(80 + 100) / 2 = 90` млн руб. Фондоотдача `180 / 90 = 2` руб./руб., фондоёмкость 0,5 руб./руб., фондовооружённость 1 млн руб./чел. Обновление `30 / 100 = 30%`, выбытие `10 / 80 = 12,5%`, прирост к началу `(100 − 80) / 80 = 25%`. Если накопленная амортизация 25 млн руб. при первоначальной стоимости на конец 100 млн руб., износ 25%, годность 75%. [ОС, 67–71]

### Скорости и фонд скважин

**Тренировка.** Проходка 1800 м, работа долота 300 ч, спуск и подъём 60 ч, 12 долот. Технически необходимые работы заняли 1,5 станко-месяца, всё бурение 2, весь цикл 2,5. Получаем `Vм = 6 м/ч`, `Vр = 5 м/ч`, `dср = 150 м/долото`, `Vт = 1200`, `Vк = 900`, `Vц = 720 м/станко-месяц`, `kи = 0,75`. [ОС, 73–81]

**Тренировка.** `Сэ = 540`, `Сд = 600`, `Ск = 720` скважино-месяцев. Эксплуатация действующих скважин `540 / 600 = 0,90`, использование всего добывающего фонда `540 / 720 = 0,75`. Фактическое время в числителе одинаковое. [ОС, 73–81]

### Оборот и запасы

**Тренировка.** За год реализовано 120 млн руб., средний остаток 20 млн руб. При 360 днях `Коб = 6`, `Кз = 1/6 ≈ 0,167 руб./руб.`, `Тоб = 60 дней`. Если при прежней выручке оборот сокращается до 54 дней, нужно `120 × 54 / 360 = 18 млн руб.`, высвобождается 2 млн руб. [ОбС, 16–17]

**По таблице «Татнефти».** Берём из строки «Запасы — всего» себестоимость на конец 2023 г. 157 154 209 и вычитаем резерв 1 123 286. Получаем 156 030 923 в масштабе исходных таблиц, что совпадает со строкой 1210 в балансе. [ОбС, 12–14]

**По таблице «Лукойла».** Начало 2022 г., все НМА: `3 690 977 − 977 151 = 2 713 826`. В третьем числовом столбце приведена балансовая стоимость, в скобках показана вычитаемая накопленная амортизация и обесценение. [НМА, 12]

## Теория и отраслевые особенности

- **ОС** — материальный актив для обычной деятельности, рассчитанный на использование свыше 12 месяцев или более длинного обычного операционного цикла и способный приносить экономические выгоды. У нефтедобычи велика доля сооружений (в лекции 70–80% ОС), прежде всего скважин. В бурении важны буровые установки, транспорт и оборудование, в магистральном транспорте — трубопроводы и компрессорные станции, в переработке — технологическое оборудование и передаточные устройства. В таблице курса скважины и трубопроводы отнесены к сооружениям активной части, здания — к пассивной. [ОС, 16], [ОС, 27–30]
- **Оценка ОС.** Первоначальная стоимость — признанные капитальные вложения до готовности к использованию. В учебных формулах возмещаемые налоги исключаются. После признания возможна модель первоначальной или переоценённой стоимости по группе. Кадастровая стоимость — результат государственной оценки недвижимости. Физический износ означает потерю технических свойств, моральный I рода — удешевление воспроизводства аналогов, моральный II рода — снижение ценности из-за появления более производительных аналогов. [ОС, 34–38], [ОС, 40], [ОС, 41–43]
- **НМА** — идентифицируемый объект без материальной формы для длительного использования, который приносит будущую выгоду, подтверждён правами и доступ к которому организация способна ограничить. Примеры: право на программу, патент, товарный знак, лицензия на деятельность при выполнении условий признания. Материальный носитель может учитываться самостоятельно. Квалификация персонала, собственная информация о клиентах и объекты для продажи в рамках обычной деятельности исключаются по критериям слайда. [НМА, 5–7]
- **Недропользование.** К нематериальным поисковым активам относят право на поиск, оценку или разведку по лицензии, данные исследований, результаты разведочного бурения и отбора образцов, иную полученную геологическую информацию и оценку коммерческой целесообразности добычи. В балансе на слайде «Татнефти» НМА, НИОКР и поисковые активы показаны отдельными строками. [НМА, 9], [НМА, 15]
- **Учёт НМА.** Единица — инвентарный объект, обычно совокупность оформленных прав. При признании базой служат капитальные вложения. Первоначальная стоимость зависит от способа получения (покупка, создание, безвозмездное получение, вклад в капитал). Для последующей оценки применяют модель первоначальной либо переоценённой стоимости по группе при соблюдении условий. СПИ зависит от срока прав и лицензий, ожидаемого использования и морального устаревания. НМА с неопределимым СПИ не амортизируют. Ликвидационная стоимость обычно нулевая, исключения связаны с обязательством третьей стороны купить объект или наличием активного рынка. [НМА, 16–22]
- **Добывающий фонд** охватывает действующие, бездействующие и осваиваемые или ожидающие освоения скважины. Действующие дали продукцию в последнем месяце отчётного периода, включая остановленные в этом месяце после выпуска продукции. Коэффициент эксплуатации сравнивает фактическое время с действующим фондом, коэффициент использования — со всем добывающим. [ОС, 73–81]
- **Оборотные средства** обслуживают один производственный цикл. Оборотные производственные фонды включают запасы, незавершённое производство, полуфабрикаты собственного изготовления и расходы будущих периодов в схеме курса. Фонды обращения включают готовую и отгруженную продукцию, средства в расчётах и деньги. Источники: собственный капитал и прибыль, краткосрочные кредиты и займы, привлечённая кредиторская задолженность. Оптимум обеспечивает непрерывность производства и реализации без лишних издержек хранения и связывания средств. [ОбС, 2–6], [ОбС, 18–19]
- **Структура оборотных средств по переделам.** Бурение — обсадные трубы, цемент и НЗП в виде недобуренной скважины, добыча — вспомогательные материалы и запасы нефти в резервуарах, транспорт — ингибиторы и запчасти, переработка — сырьё, присадки, катализаторы и готовая продукция. По таблице курса доля производственных запасов составляет 69,2% в нефтедобыче, 72,2% в нефтепереработке, 80,8% в газовой, 76,1% в нефтехимической отрасли. Это значения из учебной таблицы, а не актуальная статистика. [ОбС, 8–11]
- **Исторические формулировки.** Общая лекция содержит выдержки из старых правил об ОС и деловой репутации, а отдельная презентация по НМА показывает переход от ПБУ 14/2007 к ФСБУ 14/2022. Срок правовой охраны из учебной таблицы и СПИ актива решают разные вопросы. При вопросе по действующим правилам используй стандарт и редакцию, указанные в условии. [ОС, 89], [НМА, 4], [НМА, 13–14], [НМА, 16–22]
