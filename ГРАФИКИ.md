## Как открыть другую страницу

Возьмите точное имя PDF в [КАРТЕ](КАРТА.md). Пример для слайда 38 из материалов по ценам, из корня репозитория.

    pdftoppm -f 38 -l 38 -r 150 -png -singlefile 'РР_Ценообразование в НГК_2026.pdf' /tmp/organizazia-page

Результат — /tmp/organizazia-page.png. Для мелких таблиц увеличьте 150 до 200–250.
